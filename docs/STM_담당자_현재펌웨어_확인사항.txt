STM 담당자에게 확인할 사항 - 현재 firmware 기준

현재 PC/Python 쪽은 STM 펌웨어를 수정하지 않고,
이미 구현되어 있는 UART 명령을 그대로 사용하도록 맞췄습니다.

현재 Python이 사용할 명령:
- PING
- STATUS
- ENABLE X 1
- ENABLE Z 1
- MOVE X <distance> <speed> <accel>
- MOVE Z <distance> <speed> <accel>
- HOME X
- HOME Z
- STOP ALL
- STOP ALL SOFT
- ESTOP
- RESET

PC에서는 STATUS JSON을 계속 확인해서
mode=IDLE + 목표 좌표 도달을 실제 이동 완료로 판단합니다.

STM 담당자에게 확인/검증 부탁할 것:
1. 실제 장비에서 X/Z HOME이 정상적으로 homed=1이 되는지
2. 리밋 스위치 min/max가 실제 입력과 맞는지
3. MOVE 명령 직후 OK OK는 "명령 접수" 응답으로 사용해도 되는지
4. STATUS의 mode가 실제 이동 종료 시 IDLE로 확실히 돌아오는지
5. 실제 Tray 1~6의 X/Z 좌표(mm)
6. X축 -> Z축 순서로 이동해도 기구 간섭이 없는지
7. 속도/가속도 권장값
8. 현재 별도 PAUSE/RESUME 명령이 없는데
   STOP ALL SOFT 후 목표 위치 재명령 방식으로 사용 가능한지
9. 실제 물리 E-STOP 입력을 최종 장비에서 활성화할지
10. ERROR/FAULT 발생 시 HOME을 자동 수행하면 위험한 상황이 있는지
