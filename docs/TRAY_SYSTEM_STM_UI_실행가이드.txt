TRAY SYSTEM - STM 연동 및 UI 실행 가이드

============================================================
1. 현재 구조
============================================================

- 작업지시서 OCR → 품목/Tray 매칭 → UI → Python Backend → STM32 → 레일 동작
- 현재 STM32 미연결
- MockStageAdapter로 전체 UI/작업 흐름 테스트 가능
- 실제 STM32 연결 시 STM32StageAdapter로 교체 예정
- UI에서 Tray 이동 요청이 발생하면 Backend의 Stage API를 통해 StageAdapter로 전달되는 구조
- 현재는 Mock이 응답하고, 실제 연결 시 동일한 API를 그대로 사용하면서 실제 STM32 통신으로 변경

============================================================
2. STM 담당 확인 부분
============================================================

- backend/adapters/stm32_stage_adapter.py
  → Python ↔ STM32 실제 통신 연결 부분

- backend/adapters/tray_positions.py
  → Tray 1~6 실제 X/Z 위치값 입력 부분

- docs/STM_담당자_현재펌웨어_확인사항.txt
  → HOME / MOVE / STATUS / 리밋 / E-STOP / 오류 처리 등 확인사항 정리

실제 연결 시 확인 필요:
- Tray별 실제 위치
- 원점복귀
- 리밋스위치
- 현재 위치
- 이동 완료 판정
- 이동 중 오류
- STOP / E-STOP
- 재시작 시 HOME 필요 여부

============================================================
3. UI 실행 방법
============================================================

저장소 다운로드 또는 Clone 후 터미널 2개를 따로 실행

[1] Backend 실행

1) backend 폴더에서 PowerShell 또는 터미널 실행
2) 아래 명령 입력

uvicorn server:app --reload --port 8000

3) 정상 실행 시 아래와 비슷한 메시지 표시

Uvicorn running on http://127.0.0.1:8000
Application startup complete.

[2] Frontend 실행

1) 새 PowerShell 또는 터미널을 하나 더 실행
2) frontend 폴더로 이동
3) 처음 실행하는 PC에서는 아래 명령으로 필요한 패키지 설치

npm install

4) 설치 완료 후 아래 명령 실행

npm run dev

5) 정상 실행 시 아래와 비슷한 주소 표시

Local: http://localhost:8443/

6) 표시된 localhost 주소를 Chrome 또는 Edge에서 열면 UI 실행 가능

============================================================
4. 현재 테스트 가능한 범위
============================================================

- 작업지시서 업로드 및 OCR
- 품목 / Tray 매칭
- 작업 순서 진행
- Tray 이동 화면
- 수량 확인 Mock
- ArUco 확인 Mock
- 재배치 흐름
- 재고 차감
- 작업 이력
- Rack 배치 저장
- 프로그램 재실행 시 마지막 Rack 배치 복원
- STM 동작은 현재 Mock 상태이므로 실제 레일은 움직이지 않음

============================================================
5. 실제 STM 연결 시
============================================================

현재 server.py:

stage = MockStageAdapter()

실제 연결 후 예시:

stage = STM32StageAdapter(...)

즉 UI나 Workflow를 새로 만드는 방식이 아니라,
현재 StageAdapter 연결 부분만 실제 STM32 통신으로 변경하는 구조.

============================================================
6. 전체 흐름 요약
============================================================

작업지시서 업로드
↓
OCR 및 품목/Tray 매칭
↓
Python Workflow에서 작업 순서 관리
↓
해당 Tray 이동 요청
↓
현재: MockStageAdapter
나중: STM32StageAdapter
↓
STM32 실제 레일 이동
↓
카메라 확인
↓
다음 Tray 또는 최종 검증
↓
재배치
↓
재고 반영 / 작업 이력 저장
↓
작업 완료
